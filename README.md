# Work Dark — тёмная тема для рабочих сайтов

Единый userscript для Tampermonkey: перекрашивает **Jira**, **Confluence**, **GitLab** и **Allure TestOps** в тёмную тему.

- **jira.mts.ru** — своя палитра + перекраска на лету
- **confluence.mts.ru** — своя палитра + перекраска на лету
- **gitlab.services.mts.ru** — своя палитра + перекраска на лету
- **allure.services.mts.ru** — включена встроенная тёмная тема ТестОпса

Панели «Allure: Test Cases» и «Allure: Launches» на странице задачи Jira — это iframe с
`allure.services.mts.ru`, скрипт работает и внутри них.

## Установка

1. Поставьте расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [work-dark.user.js (raw)](https://raw.githubusercontent.com/Rufim/work-dark-theme/main/work-dark.user.js) — Tampermonkey предложит установку.

Обновления подтягиваются автоматически (`@updateURL` смотрит на этот файл).

## Режимы

Переключение — в меню Tampermonkey («Тёмная тема: …») или горячей клавишей **Alt+Shift+D**:

| Режим | Поведение |
|---|---|
| `всегда` | тёмная тема всегда (по умолчанию) |
| `как в системе` | следует `prefers-color-scheme` |
| `выключена` | сайт в исходном виде |

## Как устроено

Скрипт не заменяет стили сайтов, а перекрашивает их на лету: у каждого вычисленного
`background-color` / `color` / `border-color` определяется роль (фон или текст), цвет
переводится в OKLab и заменяется на ближайший по светлоте цвет своей палитры, с сохранением
полутона и прозрачности. Подмена происходит и в CSS-переменных (`--aui-*` у Jira/Confluence,
`--gl-*` у GitLab), и в готовых стилях, поэтому тема догоняет и то, что сайт отдал позже
(спа-навигация, дропдауны, iframe). Сверху — тонкий слой полировки под каждую из трёх систем.

У GitLab есть своя нативная тёмная тема (`gl-dark`) — если она включена, скрипт в сторону не лезет.

Allure TestOps перекрашивать не нужно: у него есть готовая тёмная палитра, которая включается
атрибутом `data-theme="dark"` на `<html>`. Скрипт выставляет его до первой отрисовки и держит
обсервером: если приложение сбросит атрибут, тема вернётся. Если в самом ТестОпсе переключить
тему вручную — она снова станет тёмной; чтобы вернуть сайту управление, выключите тему скрипта
(меню Tampermonkey или Alt+Shift+D).
